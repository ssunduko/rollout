Optional sidecar assets for this feature: real screenshots, product photos,
partner logos, avatars. List each in feature.json "assets" with what it shows:

  "assets": [{ "file": "assets/settings.png", "use": "the settings card, for the qualification section" }]

The visual-designer agent may place them inside a scene (copied into the
scene's library folder, so the library stays self-contained). Without any,
the agents draw every visual themselves.
